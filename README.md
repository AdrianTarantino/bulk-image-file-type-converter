# Simple Bulk Image Converter
Super basic image file type converter for converting entire folders.

It can convert to a from any of the supported formats in [The Pillow Python Docs](https://pillow.readthedocs.io/en/stable/handbook/image-file-formats.html).

## Using The Tool
### Install the Dependencies
```bash
pip install -r requirements.txt
```

### Setup Images Folders
1. Create `./images` and `./outputs` folders
2. Put all files into `./images`.

### Run The Code
```bash
python src/main.py
```
